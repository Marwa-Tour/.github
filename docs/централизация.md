# Централизация GitHub

Приватный репозиторий `Marwa-Tour/.github` хранит общие настройки организации.

## Что находится здесь

- `.github/workflows/validate-branch-and-commits.yml` — reusable workflow проверки веток и commits.
- `.github/pull_request_template.md` — шаблон для новых репозиториев без собственного шаблона.
- `.github/CODEOWNERS` — владельцы этого репозитория.
- `.githooks/commit-msg` — локальная проверка commits этого репозитория.

Доступ к reusable workflows разрешён private repositories всей организации через настройку Actions access `organization`.

## Подключение репозитория

В вызывающем репозитории нужен файл `.github/workflows/validate-git-conventions.yml`:

```yaml
name: Validate branch and commits

on:
  pull_request:
    branches: [main]

permissions:
  contents: read

jobs:
  validate:
    uses: Marwa-Tour/.github/.github/workflows/validate-branch-and-commits.yml@main
```

Маленький вызывающий файл обязателен: GitHub не запускает workflow другого репозитория автоматически.

## Что остаётся локально

- `CODEOWNERS`, если владельцы конкретного кода отличаются.
- `commit-msg` hook и установщик: Git запускает hooks с компьютера разработчика.
- PR template может оставаться локальным и имеет приоритет над общим.

## Изменение правил

Сначала измените и проверьте reusable workflow здесь. После merge в `main` изменения начнут использовать все подключённые репозитории. Не переименовывайте файл без одновременного обновления вызывающих workflows.
