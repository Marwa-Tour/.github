## Проект

Marwa Tour создаёт систему, которая объединяет работу с клиентами, заявками, поездками, документами и оплатами. Репозитории организации разделяют продукт, инфраструктуру, документацию и общие инженерные правила.

## Навигация

| Куда | Что находится |
|---|---|
| [Репозитории](https://github.com/orgs/Marwa-Tour/repositories) | Код и открытые компоненты организации |
| [Marwa-Tour Delivery](https://github.com/orgs/Marwa-Tour/projects/5) | Задачи, спринты и эпики · для участников |
| [Начало работы](https://github.com/Marwa-Tour/crm-docs/tree/main/работа-команды/погружение) | Пошаговое погружение · для участников |
| [Документация](https://github.com/Marwa-Tour/crm-docs) | Продуктовые и инженерные инструкции · для участников |
| [Рабочий портал](https://github.com/Marwa-Tour/.github-private) | Быстрые внутренние ссылки · для участников |

## Карта разработки

| Область | Репозиторий | Назначение |
|---|---|---|
| Рабочее окружение | `crm-workspace` | Объединение компонентов и материалы проекта |
| CRM | `crm-bitrix` | Интерфейс и интеграция с Bitrix24 |
| Инфраструктура | `crm-deploy` | Конфигурация, развёртывание и выпуск |
| Документация | `crm-docs` | Архитектура, продукт и процессы команды |
| Общие правила | `.github` | Публичный профиль, Actions и шаблоны |
| Портал команды | `.github-private` | Внутренняя стартовая страница |

Private repositories доступны только участникам организации. Публичные компоненты появятся в разделе [Repositories](https://github.com/orgs/Marwa-Tour/repositories) по мере подготовки к open source.

## Как устроена работа

```text
Идея → Issue → Ветка → Pull Request → Проверка → Выпуск
```

Полные правила не дублируются на главной: команда начинает с инструкции [«Погружение в работу»](https://github.com/Marwa-Tour/crm-docs/tree/main/работа-команды/погружение), затем использует тематические документы.
