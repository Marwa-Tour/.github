## Как мы работаем

```text
Идея → Issue → Ветка → Pull Request → Review → Выпуск
```

- Работа начинается с Issue и проверяемого результата.
- Ветки и commits связаны с номером Issue.
- Изменения проходят автоматические проверки и review.
- В основную ветку попадает один итоговый commit через Squash and merge.
